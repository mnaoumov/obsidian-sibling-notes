# Sibling Notes demo vault

This is an [Obsidian](https://obsidian.md/) vault demonstrating features of the [Sibling Notes](https://github.com/mnaoumov/obsidian-sibling-notes) plugin.

## Opening this vault

- **If you already have the plugin installed**, run the **`Sibling Notes`: Open demo vault** command — it downloads and opens the latest demo vault automatically.
- **Otherwise**, download `sibling-notes-demo-vault.zip` from the [plugin releases](https://github.com/mnaoumov/obsidian-sibling-notes/releases), unzip it, and in Obsidian choose `Manage vaults...` → `Open folder as vault` → select the `sibling-notes-demo-vault-<version>` folder it unzips into.

On first open, Obsidian treats the vault as untrusted — choose **Trust author and enable plugins** (or enable Community plugins manually), then open [00 Start](<./00 Start.md>).
